# بوت الأنظمة السعودية ⚖️

بوت تليجرام يرد بأجوبة **مختصرة** على الأسئلة الشائعة عن الأنظمة السعودية
(نظام العمل، الأحوال الشخصية، المرور، الإيجار، الجرائم المعلوماتية وغيرها).

- إذا فهم السؤال → يرسل جواباً مختصراً + رقم المحامي للتفاصيل.
- إذا ما فهم السؤال → يرسل رقم المحامي ويطلب التواصل معه.
- كل رد يحتوي **إخلاء مسؤولية**: المعلومة عامة وليست استشارة قانونية.

## التشغيل

### 1. إنشاء البوت في تليجرام
1. افتح تليجرام وكلّم [@BotFather](https://t.me/BotFather).
2. أرسل `/newbot` واتبع التعليمات (اسم البوت ثم اليوزر).
3. انسخ **التوكن** اللي بيعطيك إياه.

### 2. الإعداد
```bash
pip install -r requirements.txt
cp .env.example .env
```
ثم افتح ملف `.env` وحط:
- `TELEGRAM_BOT_TOKEN` → التوكن من BotFather.
- `LAWYER_PHONE` → رقم المحامي (مثل `+9665XXXXXXXX`).
- `LAWYER_NAME` → اسم المحامي (اختياري).

### 3. التشغيل
```bash
python bot.py
```
البوت يشتغل بنظام polling — ما يحتاج سيرفر أو دومين، يكفي أن السكربت يبقى شغالاً.

## الأوامر داخل البوت
| الأمر | الوظيفة |
|-------|---------|
| `/start` | رسالة الترحيب وقائمة المواضيع |
| `/topics` أو `/help` | عرض المواضيع المتوفرة |
| أي رسالة نصية | البوت يبحث عن أقرب موضوع ويرد بجوابه |

## تعديل وإضافة المواضيع
كل المواضيع في ملف [`faq_data.py`](faq_data.py). لإضافة موضوع جديد أضف عنصراً بنفس الشكل:

```python
{
    "title": "عنوان الموضوع",
    "keywords": ["كلمه", "كلمه ثانيه"],  # بدون "ال" التعريف وبدون تشكيل
    "answer": "الجواب المختصر (سطرين إلى أربعة أسطر).",
},
```

## الاختبارات
```bash
python test_matcher.py
```
تختبر تطبيع النص العربي ومطابقة الأسئلة بالمواضيع بدون اتصال بتليجرام.

## ⚠️ إخلاء مسؤولية
هذا البوت يقدّم **معلومات عامة فقط** وليست استشارة قانونية. للاستشارات القانونية تواصل مع المحامي.
